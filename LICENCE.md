## 🧩 About

**Ready or Not Config** is a comprehensive configuration tool for Ready or Not, featuring keybind manager, HUD customization, performance tweaks, and preset editor.

Based on popular community tools like **RoN Config Editor** and **ReadyOrNot Tweaker**.

---

## ✨ Features

### 🎮 Keybind Manager
- Custom keybinds — remap any action
- Multi-profile support — save and load different setups
- Conflict detection — avoid overlapping binds
- Macro support — bind sequences to a single key

### 🖥️ HUD & Interface
- HUD customization — move, resize, and hide elements
- Crosshair editor — design custom crosshairs
- Color themes — change UI colors
- Minimap options — adjust size and opacity

### ⚡ Performance Tweaks
- Graphics settings — fine-tune for FPS
- Network optimization — reduce latency
- Memory cleaner — free up RAM
- Launch options — configure startup parameters
